# Unicity Docs Portal

Documentation for the Unicity stack: the protocol, the AgentSphere wallet and SDK, and Unicity AOS.

This site aggregates documentation from across the Unicity GitHub organizations. Each section is pulled directly from its source repository at build time, so the content here tracks the upstream repos automatically.

## The stack

<div class="grid cards" markdown>

-   __Unicity Protocol__

    The settlement network for machine-speed commerce. Assets move directly between parties as self-contained bearer objects that carry their own proof of validity. Start with the [overview](protocol/index.md) and the [research papers](protocol/research-papers.md).

-   __AgentSphere__

    The wallet and client toolkit for autonomous economic agents: identity, payments, discovery, atomic swaps, and messaging. See the [Sphere SDK](sphere/README.md).

-   __Unicity AOS__

    A modular operating system for AI agents. Build from sealed, independently composable capsules and keep every capability under explicit control. See [Unicity AOS](agentstack/astrid.md).

</div>
